# 디자인 가이드 — 집나간 벌꿀오소리 화물 매칭

시니어 기사님이 안드로이드 폰에서 쓰는 화면. 큰 글씨, 큰 터치 영역, 높은 대비가 기본값이다.

## 0. 파일 구조

| 파일 | 화면 |
|---|---|
| `index.html` | 역할 선택 (화주 / 기사) |
| `shipper.html` | 화주 — 카톡 붙여넣기 → AI 화물 등록 → 매칭 결과 |
| `driver.html` | 기사 — 활동 지역 설정 → 추천 화물 목록 |
| `style.css` | 세 화면 공용 스타일 (단일 파일) |

## 1. ⚠️ style.css 는 3겹으로 쌓여 있다

한 셀렉터가 파일 안에서 **최대 3번** 재정의된다. 나중 것이 이긴다.

| 레이어 | 위치 | 내용 |
|---|---|---|
| v1 base | 1~338행 | 최초 보라(`#5B4FE0`) 계열. **거의 다 덮인 상태** |
| v2 cobalt | 340~393행 | 코발트 블루로 교체, sticky 헤더, 글래스 효과 |
| v3 senior | 395행~ | **실제로 보이는 값.** 폰트 확대, 테두리 굵게, 애니메이션 제거 |

**규칙: 값을 바꿀 때는 항상 v3 블록(395행 이후)에서 바꾼다.** 위쪽을 고치면 아무 일도 안 일어난다.
`:root` 토큰도 마찬가지로 두 번 선언돼 있고 342행 것이 이긴다. v3는 토큰 대신 리터럴 hex를 쓴다 —
새 값도 리터럴로 맞추는 게 혼선이 적다.

## 2. 색

실제 사용값 (v3 기준, 리터럴):

| 역할 | 값 |
|---|---|
| Primary (버튼·활성탭·강조) | `#2855d9` / hover `#2048c0` / 텍스트용 진한톤 `#2149bd` |
| Primary 배경 | `#e8eeff` (칩), `#e9edff` (상태 배지) |
| 본문 텍스트 | `#17202b` |
| 보조 텍스트 | `#586474` · `#77839a` (가장 약함) |
| 라벨 | `#8b95a6` |
| 테두리 | `#d5dae1` (카드) / `#c8ced8` (입력·버튼, 2px) |
| 배경 | `#f2f4f7` + 상단 코발트 radial glow |
| 카드 면 | `#fff` |
| 경고 | 배경 `#fff4e8`, 테두리 `#eec9a8`, 텍스트 `#8a4a12`, 아이콘 `#D98A3C` |
| 정상 | 배경 `#e5f6ef`, 텍스트 `#147653` |
| 포커스 링 | `#ffbf47` 3px, offset 2px |

다크모드는 508행 한 블록에서 통째로 처리한다. 새 컴포넌트를 만들면 여기에 색을 추가해야 한다.

## 3. 타이포

Pretendard Variable. `body` 기준 16px, `text-size-adjust:100%`.

| 요소 | 크기 / 굵기 |
|---|---|
| Hero h1 | 29px / 800 (520px 이하 27px) |
| 카드 제목 | 19px / 800 |
| 역할 선택 타이틀 | 20px / 800 |
| 본문·입력·배너 | 16px |
| 버튼·탭 | 17px / 750 |
| 보조 설명 | 14~15px |
| 라벨 | 12~13px |

**최소 크기 14px.** 그 아래는 시니어 대상에서 쓰지 않는다.

## 4. 간격 · 형태

- 반경: 카드 14px, 오퍼/기사 카드·버튼·입력 12px, 배지 8px
- 카드 패딩 20px 18px (좁은 화면 18px 16px), 카드 간격 14px
- 본문 폭 `max-width:472px`, 좌우 12px
- 그림자는 카드에만 `0 2px 8px rgba(23,32,43,.06)`. 나머지는 그림자 없이 테두리로 구분한다.

## 5. 터치 · 접근성 (타협 금지)

- 터치 타깃 최소 **52px** — 버튼, 탭, 입력 모두. 아이콘 버튼 48px
- hover 효과는 반드시 `@media (hover:hover)` 안에. 터치에서 hover가 눌어붙는다
- `:focus-visible` 노란 아웃라인 유지
- `prefers-reduced-motion` 존중 (v3는 화면 전환 애니메이션 자체를 껐다)
- 한글 줄바꿈은 `word-break:keep-all`

## 6. 컴포넌트

### 버튼
`.btn` + `.primary`(파란 채움) / `.ghost`(흰 배경, 회색 2px 테두리) / `.subtle`(연파랑).
`.row` 로 감싸면 가로 균등 분할.

### 화물 경로 — `.cargo-summary__route`
화주·기사 양쪽에서 **같은 마크업**을 쓴다. `1fr 44px 1fr` 그리드, 가운데 `→` 화살표.

```html
<div class="cargo-summary__route">
  <div class="cargo-summary__place">
    <span class="cargo-summary__label">출발지</span>
    <strong class="cargo-summary__city">대전 유성구</strong>
    <time class="cargo-summary__time">05/13 09:00</time>
  </div>
  <div class="cargo-summary__arrow" aria-hidden="true">→</div>
  <div class="cargo-summary__place">…도착지…</div>
</div>
```

### 오퍼 카드 — `.offer-card`
기사 화면의 추천 화물. 위→아래 순서가 곧 정보 우선순위다.

1. `.offer-top` — 왼쪽 `.best-label`(있으면), 오른쪽 `.badge`(`margin-left:auto`)
2. `.cargo-summary__route` — **출발지/도착지 26px**
3. `.offer-meta` — 왼쪽 `.offer-sub`(화물 스펙, 14px 연한색) / 오른쪽 `.price` (**30px/850**)
4. `.row` — 숨기기 · 수락

`.offer-card.best` 는 3px 파란 테두리로 구분한다 (그림자 없음).

**위계 원칙: 출발지·도착지·가격이 카드에서 가장 크다.** 시각·차종·톤수는 항상 그보다 작고 연하게.
`.offer-card` 안의 `cargo-summary__*` 는 481~484행에서 따로 눌러놨다 — 화주 카드와 값이 다르다.

### 배지
`.badge.ok`(적정 운임) / `.badge.warn`(운임 N% 낮음). 항상 카드 우상단.

## 7. 하지 않는 것

- 새 색 토큰을 v1 `:root` 에 추가하지 않기 (덮여서 안 먹는다)
- 14px 미만 글씨, 52px 미만 터치 타깃
- 페이지 이동 없이 화면을 감추는 UI. 세 화면은 각각 별도 HTML 파일이다
- 아이콘만 있는 버튼 — 라벨을 같이 둔다 (`.icon-btn` 새로고침이 유일한 예외)
